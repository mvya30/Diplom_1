## Задание 1: Юнит-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы юнит-тесты, покрывающие классы `Burger`

Процент покрытия 100% (отчет: `htmlcov/index.html`)

### Структура проекта

- `praktikum` - пакет, содержащий код программы
- `tests` - пакет, содержащий тесты `test_burger_.py` и т.д.

Юнит-тесты проводят следующие проверки:
1) test_initial_state - Инициализация бургера: булочка не задана, список ингредиентов пуст 
2) test_set_buns - установка булочки: булочка сохраняется в бургере
3) test_add_ingredients - добавление ингредиентов: ингредиенты добавляются в конец списка в порядке добавления
4) test_remove_ingredient - удаление ингредиента по индексу: ингредиент удаляется, остальные сохраняют порядок
5) test_remove_invalid_index - удаление по недопустимому индексу: отрицательный индекс и индекс за пределами списка вызывают IndexError
6) test_move_ingredient - перемещение ингредиента: перестановка вперёд, назад и на ту же позицию сохраняет корректный порядок(3 кейса)
7) test_price_only_buns - расчёт цены бургера только с булочкой: цена булочки учитывается дважды
8) test_price_with_ingredients - расчёт цены бургера с булочкой и ингредиентами: сумма цены булочек и всех ингредиентов 
9) test_receipt_format - формирование чека: содержит название булочки сверху и снизу, тип и название каждого ингредиента, итоговую цену
